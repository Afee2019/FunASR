# 002 - 视频转文字工具使用指南

## 工具简介

`~/dev/FunASR/scripts/transcribe_video.py` 是基于 FunASR 的视频/音频转文字工具，分两步工作：

1. **语音识别**：使用 Paraformer-zh（SeACo）+ FSMN-VAD + CT-Punc 将音频转为带标点的文字
2. **智能分段**：调用 DeepSeek Chat API 对识别结果进行语义分段和纠错

---

## 前置条件

- FunASR 已安装到当前环境：`uv pip install -e .`
- PyTorch + torchaudio 已安装：`uv pip install torch torchaudio`
- 系统已安装 ffmpeg（用于从视频中提取音轨）：`brew install ffmpeg`
- 模型首次使用会自动从 ModelScope 下载，缓存在 `~/.cache/modelscope/hub/models/`

---

## 基本用法

### 完整流程（识别 + 智能分段）

```bash
uv run python ~/dev/FunASR/scripts/transcribe_video.py /path/to/video.mkv
```

输出两个文件到视频同目录：
- `视频名_20260324_201512_raw.txt` — 原始识别结果
- `视频名_20260324_201512.txt` — 智能分段后的结果

### 复用已有识别结果，只跑分段

识别耗时较长，如果只想重新分段（比如换 prompt 调效果），可以跳过识别：

```bash
uv run python ~/dev/FunASR/scripts/transcribe_video.py /path/to/video.mkv \
    --raw /path/to/视频名_20260324_201512_raw.txt
```

### 只做识别，不做分段

```bash
uv run python ~/dev/FunASR/scripts/transcribe_video.py /path/to/video.mkv --no-segment
```

### 指定输出目录

```bash
uv run python ~/dev/FunASR/scripts/transcribe_video.py /path/to/video.mkv -o /tmp/output/
```

---

## 命令行参数

| 参数 | 说明 |
|------|------|
| `input` | 视频或音频文件路径（必填） |
| `--raw FILE` | 已有的原始识别文件，跳过识别步骤 |
| `--no-segment` | 只做识别，不调用 LLM 分段 |
| `-o DIR` | 输出目录（默认与输入文件同目录） |

---

## 支持的输入格式

- **视频**：mkv, mp4, avi, webm 等（通过 ffmpeg 提取音轨）
- **音频**：wav, mp3, flac, aac, ogg 等

前提是文件中确实有非静音的音轨。如果 VAD 检测到全是静音，会输出空文本。

---

## 处理时间参考

| 音频时长 | 识别耗时（CPU） | 分段耗时（API） |
|---------|----------------|----------------|
| 10 分钟 | 约 3-8 分钟 | 约 10-30 秒 |
| 30 分钟 | 约 10-25 分钟 | 约 20-60 秒 |

CPU 上 `batch_size` 被强制设为 0（逐片段推理），所以比 GPU 慢很多。进度条可能看起来不动，但只要 CPU 在跑就是正常的。

---

## 智能分段说明

分段由 DeepSeek Chat（`deepseek-chat`）完成，会：

1. 根据语义和话题切换分段落
2. 段落之间用空行分隔
3. 修正明显的同音字错误
4. 保留原文全部信息，不删减

DeepSeek 的 `max_tokens` 限制为 8192，超长文本可能会被截断。如果原始文本很长（超过 1 万字），分段结果可能不完整。

---

## 常见问题

### 识别结果为空

```
INFO:root:decoding, utt: xxx, empty speech
```

原因：VAD 认为音频中没有人声。通常是音轨本身是静音的（录屏软件未录到音频）。
验证：用播放器打开视频确认是否有声音。

### torchaudio 加载失败，fallback 到 ffmpeg

这是正常行为。torchaudio 2.11+ 需要 torchcodec，如果没装会自动回退到 ffmpeg 提取音频，不影响结果。

### 分段 API 超时

DeepSeek API 超时设为 300 秒。如果文本特别长，可能需要在代码中调大 `timeout` 值。
